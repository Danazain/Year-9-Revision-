1. Sequence 0–8 minutes

Python runs instructions from top to bottom. A variable can change its value.

points = 4
points = points + 2
points = points * 3
print(points)
Activity 1: What will the program display?
Need a hint?Start at 4. Add 2 first. Then multiply by 3.

2. Variables 8–15 minutes

A variable stores information. If you assign a new value, it replaces the old value.

pet = "cat"
pet = "rabbit"
print(pet)
Activity 3: What is displayed?
Activity 4: Spot the bug. The variable name must match exactly.
school_team = "Blue"
print(schoolteam)

Which line fixes the problem?

Why?Python treats school_team and schoolteam as different names. An undefined name causes a NameError.

3. Input 15–22 minutes

input() asks the user to type. It always returns text (a string). Use int() to convert valid whole-number text into an integer.

number = input("Type a number: ")
print(number + number)
Activity 5: If the user types 7, what appears?
Activity 6: Coding mission. Ask for the number of stickers. Convert it with int(). Print the number of stickers plus 5.

4. Strings 22–32 minutes

A string is text. len() counts characters. Python starts counting positions at 0.

fruit = "mango"
print(len(fruit))
print(fruit[0])
print(fruit[1:4])

Letter positions: m(0) · a(1) · n(2) · g(3) · o(4). A slice [1:4] includes positions 1, 2 and 3, but not 4.

Activity 7: What is len("mango")?
Activity 8: What does fruit[1:4] give?
Activity 9: Coding mission. Make a variable animal = "tiger". Display its length and its last letter. Run your code in Python.

5. Binary and Hexadecimal 32–42 minutes

Binary uses 0 and 1. An 8-bit number has eight digits. Hexadecimal uses 0–9 and A–F. One hex digit equals four binary bits (one nibble).

8-bit place values: 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1

Activity 10: Binary builder. Tap the bits to switch between 0 and 1. Try making 26 in denary.

Binary: 00000000 = 0

Hint26 = 16 + 8 + 2.
Activity 11: Which hexadecimal digit equals binary 1100?

Remember: A = 10, B = 11, C = 12, D = 13, E = 14, F = 15.

Activity 12: Convert hex 2A into denary.
Hint2 × 16 + A (10) = 32 + 10.
